# Description of files and folders found in: https://github.com/microbial-genomics/wu_redcedar2

| Folder/File name      | Description                                                                                                    |
| --------------------- | -------------------------------------------------------------------------------------------------------------- |
| data_out              | summary tables written by the code as output                                                                   |
| graphics              | all images                                                                                                     |
| hpc_data              | directories where the raw output from the simulation are downloaded to on a local computer for data processing |
| pointsource           | pointsource inputs to the SWAT modeling to simulate point sources over time                                    |
| src, src_hpc, src_old | all model code                                                                                                 |
| .Rdata                | R input and output data files                                                                                  |
